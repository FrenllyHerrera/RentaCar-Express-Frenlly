## Descripción del programa
Aplicación de registrar alquileres de vehículos y calcular el total a pagar.

## Datos de entrada
Cliente y fecha de salida.
Vehículo tarifa diaria y cantidad de días.
Selección de seguro  GPS y tipo de entrega 

## Proceso
Se calcula la tarifa diaria sumando recargos por seguro y GPS.
Se acumula el subtotal de los vehículos agregados a la lista.
Se aplica el descuento corporativo (15%) el cargo por entrega a domicilio y el ITBIS (18%).

## Salida
Lista de vehículos con formato de columnas en pantalla.
Desglose visual de subtotal, descuento, domicilio, ITBIS y total a pagar.
